# AI Provider Match

## What it does

AI Provider Match helps someone find a good home service provider. A user describes a problem in normal words, and the app figures out the service type, finds related provider information, ranks the choices, and explains the results.

## What I built

I built the intent reader, local RAG search, provider ranking, safety checks, explanation cards, evaluation tests, and simple web app. The project uses fictional local data, so no real business claims or API keys are included.
