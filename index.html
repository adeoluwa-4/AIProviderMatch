How this demo works

The app chunks each fictional provider profile, embeds those passages into a 192-dimensional local vector index, and retrieves the closest evidence with cosine similarity. A hybrid ranker combines that semantic score with category fit, specialty overlap, availability, coverage, quality, and distance.

The embedding model uses deterministic feature hashing rather than claiming to call a hosted neural model. It keeps requests in the browser and makes every result reproducible. The embedding adapter can later be replaced with a hosted model without changing retrieval or ranking.
