How this demo works

The app converts a natural-language service request into a small intent schema, retrieves providers by trade and service area, then ranks them using category fit, specialty overlap, availability, location, demo quality, and distance.

Mock mode is intentional: it makes every decision reproducible and keeps private requests in the browser. A production version could replace the extractor and data source behind the same module boundaries.
